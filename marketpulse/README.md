# MX Cartera Global (marketpulse)

App Next.js de seguimiento de mercados (México, SIC, EE.UU.).

## Requisitos
- Node.js 24.x

## Arranque local
```bash
npm install
npm run dev
```

## Variables
Copia `.env.example` a `.env.local`. No subas secretos a Git.

## Deploy Vercel
Root directory: `marketpulse`. Repo privado: `muecojulio/mxcarteraglobal`.
